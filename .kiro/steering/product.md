# Product

This repo is a hands-on seismo bring-up: wire the S3, IMU, and display, flash stage firmware, and write it up as a Zensical walkthrough.

We’re building a local station (lab magnitude + waveform on the TFT). Not AWS IoT, not SeedLink/SeisComP, not a multi-board fleet.

Fleet/AWS stuff belongs in `esp32-aws-iot-fleet`. Docs style to copy: `ubuntu-server-walkthrough`.
